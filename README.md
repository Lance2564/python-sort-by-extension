# python-sort-by-extension
This is a fun python project I made, it uses Pathlib to sort your files based on its extension

How to use,

git clone https://github.com/Lancee2564/python-sort-by-extension.git "Path"
cd "Path"/project
python3 main.py

This does require python 3.6 or above. 

This will not perform recursive sorting which is usually the desired effect
